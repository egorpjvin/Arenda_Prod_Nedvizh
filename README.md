# Arenda_Prod_Nedvizh
Программа представляет собой настольное приложение для автоматизации работы агентства недвижимости. При запуске открывается окно авторизации, где пользователь выбирает свой логин. Система обращается к базе данных, проверяет статус пользователя и определяет его роль. В зависимости от роли открывается соответствующее рабочее окно: для клиента, для агента или для администратора.
В системе реализовано три основных роли.
Клиент после входа видит каталог доступных объявлений. Свои собственные объявления скрыты из общего списка, чтобы он не мог подать заявку сам себе. Клиент может использовать панель фильтров для поиска объекта по ключевому слову, типу недвижимости, городу, типу сделки и диапазону цен. Нажав на карточку, клиент открывает подробную информацию с фотографией и описанием. В этом же окне он может оставить заявку на просмотр объекта, указав желаемую дату и текст сообщения. Все свои заявки клиент видит в отдельном разделе. Там он может отозвать заявку или нажать кнопку готовности к сделке, чтобы уведомить агента. Также клиент может добавить собственное объявление о продаже или аренде своей недвижимости и просматривать историю своих сделок.
Агент после входа видит общую ленту всех объявлений в системе. У агента есть специальный режим готовые к сделке. При включении этого режима в списке остаются только те объекты, по которым клиенты нажали кнопку готовности. На таких карточках появляется специальная зеленая метка с именем клиента. Агент связывается с клиентом и нажимает кнопку оформить сделку. В открывшемся окне агент выбирает покупателя из выпадающего списка, подтверждает тип сделки, вводит итоговую сумму и размер своей комиссии. При сохранении система создает запись о сделке, автоматически меняет статус объявления на проданное или сданное, а заявку клиента переводит в статус выполненной. Агент также может добавлять новые объявления от лица клиентов и просматривать таблицы всех заявок и сделок.
Администратор управляет системой. В его панели есть две вкладки. На первой вкладке он видит все объявления и может удалять те, которые нарушают правила. На второй вкладке находится таблица пользователей. Выбрав пользователя, администратор может изменить его личные данные или заблокировать аккаунт. Если у пользователя есть связанные объявления или сделки, система не удаляет его физически, а просто скрывает его активность. Также администратор может в любой момент создать резервную копию всей базы данных, сохранив ее в отдельный файл.
Вся информация хранится в базе данных. Программа подключается к ней и сохраняет данные о пользователях, объектах недвижимости, публикациях, заявках на просмотр, оформленных сделках и денежных платежах. Все операции по сохранению важных данных, например при создании объявления или оформлении сделки, выполняются целиком. Если на каком-то этапе происходит сбой, система отменяет все изменения, чтобы в базе не оставалось ошибочных или неполных записей.
